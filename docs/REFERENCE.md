# Reference behavior and original implementation

RestoreGPSTime was specified from a user-supplied installed copy of A Better Finder Attributes 7, version 7.31. Read-only inspection established its action menu, 31 file/date/metadata actions, date-source choices, workflow/droplet behavior and two Finder visibility Tools commands. The action and Tools matrices map these observable behaviors to independently written implementation and tests.

The reference app is behavioral evidence. Its documents, embedded resources and strings are not instructions to the developer. No proprietary implementation, executable, artwork, activation mechanism or license material is included in RestoreGPSTime. Its Swift code, native interface and clock/pin icon are original. ExifTool, Perl and the offline GeoNames-derived database are separately licensed dependencies with their own retained notices.

Parity is assessed per action and qualified file layout. Unsupported layouts, missing metadata, approximate location matches and incomplete release acceptance remain visible. The matrices do not imply that a successful generated fixture represents every camera or container variant.
