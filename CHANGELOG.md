# Changelog

## 0.2.0

- Independent tab previews, combined with **Apply Changes**.
- Preview before choosing a copies folder.
- Space-saving metadata backups by default, with per-file undo.
- Optional thumbnails, green proposed columns and remembered settings.
- Fixed some HEIC files being blocked when saving place names.

## 0.1.2

- Automatically handle missing UTC offsets using GPS time zones and a batch fallback.
- Show the app version in the window header.
- Faster batch metadata reading, preview progress and grouped blocked reasons.

## 0.1.0

- Restore photo and video dates from metadata.
- Recover place names from GPS offline and rename files in batches.
- Save copies or modify originals with backup and undo.
